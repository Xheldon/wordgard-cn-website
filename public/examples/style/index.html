示例：样式

与浏览器中的其他元素一样，Wordgard 编辑器的外观由 CSS 样式规则决定。为了支持将样式作为扩展的一部分，而无需为每个扩展单独加载 CSS 文件，该库采用 CSS-in-JS 系统，自动注入与其所属代码捆绑在一起的样式。

您可以使用常规 CSS 规则为编辑器设置样式，但请记住，通过扩展提供的样式会额外添加一个类选择器，这使得它们的优先级高于您的普通规则，除非您自行添加一些特定的选择器。

前缀类

本系统中有两种类型的样式包：一种是始终适用的样式包，另一种是仅在其所属的主题激活时才适用的样式包。前者仍需包含在配置文件中（因为这是编辑器确保其被加载的方式），但它们无法通过添加或移除扩展来开启或关闭。

第一种类型使用 Wordgard.styles 定义：

let styles = Wordgard.styles({
  ".my-widget": {
    border: "2px solid purple",
    backgroundColor: "orange"
  }
})

如果您包含该扩展，编辑器内具有 my-widget 类的元素将获得指定的样式。您应该在此类样式集中针对特定于您扩展的元素和类，以免干扰其他内容。

对于需要显式选择加入的样式集，请使用 Wordgard.theme：

let theme = Wordgard.theme({
  "wg-content": {
    lineHeight: "1.6"
  }
})

此类主题仅会在明确包含它的编辑器中生效。这非常有用，因为您不希望文档中的所有编辑器在您于某个编辑器中使用此主题时，突然都获得新的行高。

其工作原理是：存在一个 facet，用于控制编辑器根节点（window、frame 或 shadow root）中加载哪些样式。当您定义一组样式或主题时，返回的扩展将包含该 facet 的值。

此类模块中的所有规则均带有由库唯一生成的额外类名前缀。对于常规样式集，该类是稳定的，并且始终存在于编辑器上。主题拥有其自身的类，该类仅存在于启用了该主题的编辑器上。

由于这些作用域类最终会出现在编辑器的外部元素上，如果您的规则直接引用了该元素，则必须通过在应出现该位置包含 & 来告知库插入类选择器。例如，此扩展在编辑器具有 faint 类时对其进行样式设置。

let faintSupport = Wordgard.styles({
  "&.faint": {opacity: "0.5"}
})

配色方案

您还可以使用特殊标记 &light 和 &dark，它们的工作原理类似，但仅匹配使用浅色或深色 配色方案 的编辑器。

默认情况下，编辑器使用浅色配色方案。您可以使用 Wordgard.colorScheme.of("dark") 指示其使用深色方案。但请注意，这仅切换使用 &light 或 &dark 规则。默认编辑器样式并不包含在深色配色方案中将背景设为深色或将文本颜色设为浅色的规则——您必须自行处理，要么确保从编辑器父元素级联下来的颜色符合该方案，要么通过扩展直接提供所需的样式。

或者，如果您的页面已经使用了 CSS prefers-color-scheme 功能，您可以将编辑器配置为 Wordgard.colorScheme.of("auto")，使其颜色方案自动跟随首选方案。

规则表示法

正如您在迄今为止的示例中所见，样式是以某种变体的 JavaScript 对象 CSS 表示法提供的。您传递给 Wordgard.styles 或 Wordgard.theme 的对象包含作为属性名的选择器，以及定义样式属性的对象作为其值。属性名可以使用驼峰命名法，它将被规范化为 CSS 连字符表示法（fontFamily → font-family）。属性值应为字符串。

可以通过在这些属性中包含带有 & 标记的属性来嵌套规则，如下所示：

let myPanelStyle = Wordgard.styles({
  "wg-panel.my-panel": {
    borderBottom: "2px solid black",
    "& p": {
      padding: "0 10px"
    }
  }
})

此样式为 `my-panel` 面板内的段落设置较小的水平边距。

您还可以将某些规则包装在特定类型的 @ 块中，如下所示：

Wordgard.theme({
  "@media screen and (min-width: 400px)": {
    "wg-content": {
      fontSize: "2rem"
    }
  }
})

DOM 结构

编辑器的外部元素使用 <wordgard-editor> 标签名，不过您在规则中通常希望使用 & 选择器来定位它。这是一个垂直弹性盒子，用于容纳 滚动条元素、面板 和 工具提示。

滚动器是一个 <wg-scroller> 元素。默认情况下，它实际上不会滚动，但对该元素进行样式设置是创建一个拥有独立滚动条的编辑器的方式（例如通过 Wordgard.scrolling）。

其内部是 <wg-content> 元素，该元素承载实际的可编辑文档。此元素启用了 contenteditable 属性，并包含多个与编辑相关的属性（例如 role="textbox"），当编辑器内容获得焦点时，该元素即为获得焦点的元素。

在内容的同一父级中还有一个 `<wg-cursor-layer>` 元素，它覆盖在内容之上，并用于将自定义光标绘制为 `<wg-cursor>` 元素。

存在用于向编辑器的 外部 元素和 内容 元素添加属性的扩展。这些扩展在根据编辑器状态添加类以影响特定情况下的样式时非常有用。

可以通过针对用于绘制编辑器内容的元素 样式化 来设置编辑器内容的样式。不过，编辑器对其内容的布局有一些假设，您应注意不要违反这些假设。首先，内联内容应渲染为内联元素（因此请勿将文本块设置为 display: flex 或类似样式），并且块应沿一个方向布局其内容；如果该方向不是垂直方向，则应声明自身具有 行方向。

编辑器自身的样式定义了一些在自定义样式中可能很有用的 CSS 变量：

  • --wg-highlight-color 是用于选中元素和焦点环的颜色。默认值为亮蓝色。
  • --wg-dialog-font 是一种用于对话框和工具提示的 font 样式。
  • --wg-border-color 是用于编辑器及其界面元素边框的颜色。
  • --wg-panel-color 是 面板 和 工具提示 的背景色。
