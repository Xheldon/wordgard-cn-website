参考手册
这是 Wordgard 的参考手册。它列出了库公共接口中每种类型和值的完整列表。


Wordgard 作为一个包（"wordgard"）发布，该包导出了多个独立的模块，其名称类似于 "wordgard/doc" 或 "wordgard/editor"。这些模块的划分方式使得每个模块都定义了系统的一个自包含部分。在某些情况下，例如在没有编辑器的情况下操作文档时，您只需要其中少数几个模块。而要设置一个功能完整的编辑器，则需要使用其中大部分模块。


这些是模块：


    

  • wordgard/doc 定义了文档模型和变更表示。
    • 

  • wordgard/state 定义了编辑器状态、选区和事务类型。
    • 

  • wordgard/editor 实现了编辑器接口组件，以及直接作用于该接口的扩展接口部分。
    • 

  • wordgard/command 提供编辑命令抽象以及一系列通用命令。
    • 

  • wordgard/history 实现了撤销/重做历史记录。
    • 

  • wordgard/schema-def 导出了该包提供的所有文档元素的定义。
    • 

  • wordgard/schema 提供了这些模式元素的包装器，这些包装器添加了编辑支持功能，例如菜单按钮和键盘绑定。
    • 

  • wordgard/table 提供了表格支持的实现。
    • 

  • wordgard/collab 实现了协同编辑的原语。
    • 

  • wordgard/phrases 导出可用于翻译编辑器界面的短语集。
    • 



设置一个简单的编辑器可能如下所示：


import {Wordgard, defaultKeymap, menuBar} from "wordgard/editor"
import {fullSchema} from "wordgard/schema"
import {history} from "wordgard/history"

const editor = Wordgard.create({
  parent: document.body,
  doc: `<p>The initial document</p>`,
  config: [fullSchema(), defaultKeymap, history(), menuBar()]
})

Document


文档是一棵节点树。它由以下元素组成：


    

  • 节点 可以是 图表（带有内容的节点）或 叶子。顶层文档节点是一个图表。
    • 

  • 每个节点都有一个 类型。
    • 

  • 标记是附加到节点上的信息片段。它们用于文本样式、图像替代文本或块对齐等功能。
    • 

  • 标签描述了节点的性质，它结合了
节点类型、一个可选的参数值以及
一组标记。叶子节点 是 标签，而绘图节点
拥有 标签。
    •

class KeyBinding {





键绑定将按键与应在发生匹配的键盘事件时运行的功能关联起来。


键绑定可以指定要匹配的特定 字符，该字符将与按键事件产生的实际字符进行比较，或者描述一个 键组合。


对于给定的键盘事件，绑定将按照优先级顺序进行评估，每个绑定都有机会处理该事件，直到第一个处理程序返回 true 时停止。


键组合由类似 "Shift-Ctrl-Enter" 的字符串描述——即在零个或多个修饰符后跟一个键标识符。键标识符基于可出现在 KeyEvent.key 中的字符串。请使用小写字母来指代字母键。您可以使用 "Space" 作为 " " 名称的别名。


修饰符可以按任意顺序给出。系统可识别 Shift-（或 s-）、Alt-（或 a-）、Ctrl-（或 c- 或 Control-）以及 Cmd-（或 m- 或 Meta-）。


您可以使用 Mod- 作为 Mac 上 Cmd- 和其他平台上 Ctrl- 的简写。因此，Mod-b 在 Linux 上是 Ctrl-b，而在 macOS 上是 Cmd-b。

装饰提供了一种通过编辑器扩展来影响文档显示方式的方法，而无需更改文档本身。它们可用于在可编辑内容中直接显示带外信息或编辑控件。

Command Abstraction


命令函数由键绑定、菜单和事件处理程序等使用，用于分发特定类型的用户操作。它们具有参数类型（可能为 null 并被忽略）。




type Command<Param = null> = (
  target: Wordgard,
  param: Param
) => boolean | Transaction.Spec





命令是一个函数，它接收一个编辑器和一个附加参数，然后要么……


    

  • 返回 false 以表示其不适用于当前的编辑器状态。
    • 

  • 作为副作用执行其操作并返回 true
    • 

  • 返回一个应作为其效果分派的事务规范。
    • 



此公式的选用旨在涵盖具有副作用的命令（其影响甚至可能不直接作用于编辑器——命令可能仅打开对话框或更改某些编辑器外部状态）以及实现为从状态到事务的纯函数的命令。


扩展可以为命令注册额外的处理程序，当命令被分发时，这些处理程序将按优先级顺序调用（直到其中一个返回 true）。命令通过函数身份进行识别。因此，例如，enter命令既是用于指示触发回车键按下的标签，也是实现此操作默认行为的函数。

  param: Param
) => false | Transaction.Spec





Command.Pure 是 Command 的子类型，它仅依赖于编辑器状态，且不执行任何命令式副作用。在实现此类命令函数时，使用此类型进行标记会很有用，这样可以在没有完整编辑器组件的情况下调用它，以便进行测试或在没有编辑器的环境中使用。

单元格选择是一种自定义选择类型，它不跨越两个文档位置之间的范围，而是跨越同一表格中两个单元格之间的矩形区域。它附带扩展功能，确保以可识别的方式绘制，在选区跨越单元格边界时自动创建，并根据键盘和鼠标操作进行适当调整。




  anchorCell: number





作为此选择锚点的单元格正前方的位置。




  headCell: number





作为选择头的单元格正前方的位置。




  moveHead(
    doc: Plot.Doc,
    dir: "forward" | "backward" | "up" | "down"
  ): CellSelection | null





将表头单元格沿指定方向移动，如果可以选择扩展，则返回新的单元格选择。




  static between(
    doc: Plot.Doc,
    anchor: number,
    head: number
  ): CellSelection | null





在给定两点之间创建表格选择。这些点应分别位于所选第一个单元格之前和最后一个单元格之后（anchor 可在 head 之前或之后，只要较低的值位于某个单元格之前，较高的值位于某个单元格之后即可）。如果给定范围未包含单个表格中的一组单元格，则返回 null。




  static normalize(
    sel: GardSelection,
    doc: Plot.Doc
  ): GardSelection | null





给定一个选区，如果该选区有效（即单元格选区，或起始和结束位置均在表格之外，或位于同一表格单元格内），则返回 null。否则，它会将单个表格内的选区扩展为单元格选区，或将跨越表格边界的选区扩展以覆盖整个表格。




  static extension: GardState.Extension





此对象可用作扩展以启用单元格选择。




}

class PhraseSet<Tags extends string> {





短语集定义了要在用户界面中显示的一组文本短语，并使得这些短语的翻译成为可能。它将每个短语与一个标签关联起来。此类的类型参数是其定义的标签名称集合。




  phrases: any



  get<Tag extends Tags>(
    state: GardState,
    tag: Tag,
    ...insert: any[]
  ): string





查找带有指定标签的短语的翻译。


如果传递了额外的参数，它们将替换占位符，例如 $1（对应第一个值）和 $2 等。单个 $ 等同于 $1，而 $$ 将生成一个字面美元符号。




  ref<Tag extends Tags>(tag: Tag): PhraseSet.Ref





创建一个短语的引用。返回一个函数，该函数可接受编辑器状态作为参数，以获取短语文本。




  translate(phrases: any): GardState.Extension





创建此集合的翻译。将生成的扩展添加到编辑器配置中，将导致访问该集合中的短语时返回翻译后的文本。




  translatePartial(phrases: any): GardState.Extension





创建此集合的部分翻译。与 translate 的唯一区别是，当省略某些标签时，此方法不会引发类型错误。




  static define<
    Tags extends string
  >(phrases: {[tag in Tags]: string}): PhraseSet<Tags>





定义一个新的短语集。接受一个对象作为参数，该对象定义了该集中所有标签的默认（通常为英文）文本。




  static didChange(a: GardState, b: GardState): boolean





检查短语集配置是否在给定的两个状态之间发生了变化。可用于检查界面的某些部分是否需要重绘。




}
