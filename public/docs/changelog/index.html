版本 0.6.0（2026-10-17）

破坏性变更

RangeSet 和 PointSet 的接口已更改，现在它们从 wordgard/set 导出。

handlePaste 处理程序现在接收的是 InputEvent，而不是 ClipboardEvent。

对话框不再显示为面板，而是作为浮动元素显示在编辑器上方。

Dialog.show 返回的 close 值现在是一个函数，而不是一个效果。

Dialog.close 已不再存在。取而代之的是，请使用 Dialog.get 通过其键查找对话框，然后调用返回结果上的 close 方法。

变更集现在存储纯令牌数组，而不是 Slice 对象。这在 iterChanges 和类型的 JSON 表示中可见。

Plot.Doc.slice 现在返回一个令牌数组，而不是 Slice 对象。

多个曾将上下文作为独立参数传递的剪贴板相关组件现已丢失该参数，现在需要从切片中获取它。

parse.slice 不再返回包含切片和上下文的包装对象，因为上下文现已包含在切片中。

serialize.slice 不再将切片的上下文作为选项接收，而是从切片对象中获取。

键位绑定的“作用域”功能已不再受支持。

键绑定规范不再允许为修饰符使用别名（如 s-），且修饰符名称现在区分大小写。

Decoration.Tag.shape.dynamic 和 .widget.dynamic 现在称为 .derived。

TextblockMap.visualSide 已不再存在（块开头/结尾的位置现在始终用内容的实际开头/结尾位置表示）。

Facet.compute/computeN 已重命名为 derive/deriveN。

错误修复

修复了一个导致当编辑器被包裹在阴影根中时子菜单立即关闭的问题。

确保在解释输入事件范围时使用待处理的选区更改。

当 posAtCoords 无法找到位置时，避免栈溢出。

在适配替换项时，更积极地使用定义上下文节点。

修复了一个问题，该问题会导致 nodeFromDOM 返回节点的过时版本。

修复了一个在组合旁边插入文本时会破坏组合的问题。

确保因内容变更而中断的构图能够被干净地终止。

处理 Safari 对组合输入 beforeinput 事件的过时实现。

修复了一个问题：当浏览器标签页失去焦点后又重新获得焦点时，自定义选择类型会被重置为纯文本选择。

wordgard/doc 的类型声明不再为 Pos.nextSibling/previousSibling 提供错误的类型。

确保 splitTextblock 不会尝试拆分隔离块。

修复了在表格单元格中按下 End 键会跳转到下一个单元格的问题。

确保删除键/退格键不会尝试跨越表格单元格或其他隔离节点。

单元格选择具有一个 toSlice 方法，该方法会生成包含其内容的正确切片，从而确保复制单元格选择时能正确执行。

当编辑器内容的高度发生变化时，发送一个带有 geometryChanged 标志的更新。确保光标保持在正确的位置。

新功能

decoratePlots 函数可用于为指定类型的所有图表内容添加装饰。

wordgard/highlight-code 包提供基本的代码块语法高亮功能。

支持影响选定内容以外内容的粘贴事件。

codeBlock 现在包含了一些样式，使代码块更易于识别。

选择类现在拥有一个 toSlice 方法，用于将选定的内容转换为切片。

对话框现在可以指定一个 tooltip 选项，以便将其定位在文档位置的附近。

对话框现在支持一个 closedBy 选项，使其能够针对特定类型的交易自动关闭。

新的 PositioningHint 对象可用于为对话框（或其他 UI 元素）提供出现位置的提示。

Slice 对象现在可以包含上下文数组。Slice.get 会构建一个带有相关上下文的切片。

新的 keyBindingHelp 扩展可以在对话框中显示编辑器当前活动的键盘绑定。

KeyBinding.lookupByDescription 现在可用于查找分配给某项功能的按键。

菜单栏现在显示键盘快捷键，既在项目的 title 属性中，也在 aria-keyshortcuts 属性中。

Decoration.Mark.shape 现在可用于更改标记在编辑器内的渲染方式。

通过双击等操作创建的选区现在在首次扩展之前没有方向。

新的 GardState.Field.Derived 类可用于定义状态的派生值，从而允许您通过 state.field(...) 读取它们。
