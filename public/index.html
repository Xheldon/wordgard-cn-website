Wordgard [wɜrd-gɑrd] 名词 培育词语的花园。 一个开源 JavaScript 库，实现了浏览器内的富文本编辑器。

语义富文本编辑器系统

Wordgard 提供了一套用于构建内容编辑器的工具。它不是一个自由形式的 HTML 编辑器，而是一个让您能够精确控制所支持内容类型的编辑器。

其主要区别在于强大的编程接口，这使得该库成为定制编辑器（即使是复杂且要求苛刻的编辑器）的良好基础。

功能

  • 基于模式

    精确定义文档的结构。创建自定义文档元素。

  • Deluxe API

    编辑器的编程接口经过精心打磨，旨在实现高度的通用性与多功能性。

  • 模块化

    大多数编辑器功能均以扩展形式实现，这意味着当它们无法满足您的需求时，您可以替换或修改它们。

  • 无障碍

    适用于屏幕阅读器用户、仅使用键盘的用户以及移动设备。支持用户界面国际化。

  • 从右向左书写

    内容和界面均支持方向感知。支持双向内容以及从右向左的文档。

  • 结构化内容

    文档树可以包含表格、嵌套列表、带标题的图形以及自定义结构。

  • 函数式

    系统的大部分代码采用函数式风格编写，以确保清晰性和可测试性。

  • 协同编辑

    支持多名用户同时编辑同一文档，并合并并发编辑。
